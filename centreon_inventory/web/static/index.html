Définir un client

Le périmètre d'un client se définit par le nom des hôtes, leurs groupes d'hôtes, leur collecteur et/ou le nom des services. Les critères d'hôte renseignés se cumulent. Plusieurs valeurs séparées par des virgules ; * = n'importe quels caractères (ex. ctg-eple-973-*) ; préfixe re: pour une expression régulière. Avec « Limiter la collecte au client », seuls ces hôtes sont collectés.
